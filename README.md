# planar-l1-lean

A conditional Lean 4 / Mathlib formalisation of selected lemmas from OpenAI's preprint
*Planar Graph Metrics Embed into L1 with Constant Distortion* (23 September 2026):
https://github.com/openai/math/blob/main/preprints/Planar-Graph-Metrics-Embed-into-L1-with-Constant-Distortion-September-23-2026/paper.pdf

Scope: parts of Sections 3, 5 and 6. Anything those lean on from other sections (Section 2 geometry, Theorem 4.1)
is stated as an explicit hypothesis. It is NOT a proof of the paper's main theorem, and no `sorry` or new axiom is allowed.
`NOTES.md` has plain-language notes on the sections. `TASKS.md` is the work list and the rules.
Started by Keith Adler with Claude; unaffiliated with the paper's authors.
